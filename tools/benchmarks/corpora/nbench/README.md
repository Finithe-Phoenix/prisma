# nbench Benchmark

BYTE Magazine's BYTEmark benchmark program (nbench) is a popular suite to test CPU/FPU/memory performance.

Source: https://www.tux.org/~mayer/linux/bmark.html

## Building

Run `./build.sh` to download and compile the benchmark.

Prerequisites:
- `x86_64-linux-gnu-gcc`
- `wget`
- `make`
